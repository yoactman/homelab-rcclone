Privacy Policy

Last updated: September 28, 2026

Homelab rclone is a personal, non-commercial application used by its owner to store encrypted homelab backups in Google Drive.

Data accessed

The application uses the Google Drive API with the drive.file scope. It accesses only files and folders that the application creates or that are explicitly made available to it.

How data is used

Google Drive access is used solely to create, read, update, and manage backup files required for the owner's personal backup system.

Encryption

Backup contents are encrypted with Restic before storage in Google Drive. The encryption password and local authentication credentials are kept outside this public website and are not published in this repository.

Sharing and sale of data

No user data is sold, rented, shared for advertising, or provided to third parties for unrelated purposes.

Data retention and deletion

Backup retention is controlled by the owner of the application. Backup data can be deleted from Google Drive as part of the owner's backup retention and maintenance procedures.

Third-party users

This application is not offered to the public and does not provide accounts or services to third-party users.

Changes

This policy may be updated if the backup architecture or Google Drive integration changes.
