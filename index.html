Homelab rclone

Homelab rclone is a personal, non-commercial utility used to store encrypted backups from a private homelab in Google Drive.

The application uses rclone to connect to Google Drive and Restic to encrypt backup data before it is uploaded.

Google Drive access

The application requests the drive.file scope. This scope limits access to files and folders created or explicitly opened by the application; it does not provide general access to unrelated files in the user's Google Drive.

Use

This application is intended only for the owner's personal backup infrastructure. It is not offered as a public service and does not provide accounts for third parties.
